# Review Page

Basit bir HTML sayfası olarak tasarlanmış bu proje, kullanıcı yorumlarını sergileyen bir yapı sunar.

## Özellikler

- **Yorum Listesi**: Kullanıcı yorumlarını listeleyen bir yapı içerir.
- **Responsive Tasarım**: Mobil uyumlu, tablet ve masaüstü cihazlarda düzgün görüntülenir.
- **Kolay Özelleştirme**: HTML dosyasını düzenleyerek içerik ve stil üzerinde değişiklikler yapabilirsiniz.
